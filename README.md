# NoxInfluencer Ultra (Auto)

个人自用的 NoxInfluencer 油猴脚本,在原 helper 基础上增加**全局自动化**。

## 全自动流程(YouTube + Instagram + TikTok 跨平台)
1. 在搜索页调好筛选条件(地区/粉丝/邮箱/性别等),搜索一次让 URL 带上 `?p=`
2. 点面板里 **🚀 全自动**,粘贴关键词(每行一个)、设定每批目标结果数(默认 1万)、日期前缀
3. 脚本把当天匹配的收藏夹**列进多选框并全选**,可取消掉想用别的方法找达人的那几个,
   再点 **✅ 确认开始** 才正式开跑
4. 脚本自动:用 YouTube 逐词累加探测结果数 → 够一批就定批 → 依次在
   **YouTube → Instagram → TikTok** 各搜一次并收藏(同一套词/筛选,共用当天收藏夹)
   → 三平台跑完进下一批,直到词用完
5. 只收进你勾选的当天收藏夹(名字含 m 的上限 500,其余 1000,满了自动换下一个),三平台共用
5. 进度存 localStorage,跨页面跳转/刷新可续跑;残留任务再打开会弹确认;点「停止全自动」清理

## 被人机验证打断怎么办
- 任务进度存在浏览器 localStorage,不会因跳转丢失
- 脚本全站加载:被验证甩到首页后,顶部会出现紫色提示条,5 秒倒计时后**自动跳回**该批词的搜索页续跑
- 提示条上可点「立即继续」马上跳,或「留在本页」取消自动跳(比如你想先手动过验证)
- 注意:collect 阶段被打断后跳回是从第 1 页重收,已在收藏夹的达人会被跳过(幂等),不会重复占名额太多

## 说明
- 词数上限:搜索框最多 20 个词(含排除词),脚本加词到顶会直接定批
- 探测只在 YouTube 做一次定批,其余平台复用同一批词

保留了原脚本的全部功能(搜索收藏、关键词输入、批量建收藏夹、email、CRM)。
