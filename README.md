# NoxInfluencer Ultra (Auto)

个人自用的 NoxInfluencer 油猴脚本,在原 helper 基础上增加**全局自动化**。

## 全自动流程(当前:YouTube 单平台)
1. 在搜索页调好筛选条件(地区/粉丝/邮箱/性别等),搜索一次让 URL 带上 `?p=`
2. 点面板里 **🚀 全自动**,粘贴关键词(每行一个)、设定每批目标结果数(默认 1万)
3. 脚本自动:逐词累加探测结果数 → 够一批就搜 → 自动收藏进当天日期前缀的收藏夹
   (名字含 m 的上限 500,其余 1000,满了自动换下一个)→ 下一批,直到词用完
4. 进度存 localStorage,跨页面跳转/刷新可续跑;点「停止全自动」清理
